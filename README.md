# combank-pro-api

X-Poker Halloween Lucky Draw API (NestJS + Supabase).

## Setup

1. Copy `.env.example` → `.env` and fill secrets (`JWT_SECRET` ≥ 32 chars, no `change-me`)
2. `npm install`
3. `npm run start:dev`

## Scripts

- `npm run build` / `npm start` — production
- `npm run create-admin` — create admin user
- `npm run smoke-test` — basic API smoke test
